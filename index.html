When is memory worth more than forgetting?

Astra found the missing attacker: one tiny model with aggressive forgetting beats the original growing system overall. So 368 now separates adapt, retain, retrieve, and investigate.

adapt fast→surprise→provisional memory→future audit→retain→retrieve if evidence fits

The audit fixes the old shared-noise-stream problem and matches observation budgets. In this toy, both what to ask and when to ask contribute. The PING is useful for retrieval; it still does not decide which memories deserve long-term existence.

Successful fit may earn a memory's birth. Only useful recurrence can earn its survival.
